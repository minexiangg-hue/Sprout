# Sprout 演示操作与恢复

## 演示前

运行 `corepack pnpm dev`，打开 http://127.0.0.1:5173/ 。建议 1440×1000 或更大屏幕，浏览器缩放 100%。桌面中文字体自托管，首次加载等待字体完成。

准备三个窗口：工坊首页、已经搭完的接星星作品、`docs/pitch-deck.html`。新安装没作品时，先完成以下配方流程；它不依赖网络。不要把预制作品冒称现场生成。

## 90 秒稳定现场演示（确定性示例）

1. 明说「现在走无需联网的示例配方；真实 AI 的另一次实测记录也在仓库里」。点击「把星星装进口袋」，再点「让想法发芽」。
2. 展示四块模块：画面 `scene.html`、设计 `style.css`、规则 `main.js`、反馈 `celebrate.js`。依赖标签表示先后关系；点开能看到概念与源码。
3. 连续点击四次「搭建下一块」。每次会保存进度，预览逐步出现；它不是加载动画后同时宣称完成。
4. 点击预览内「开始接星星」。鼠标/触摸移动篮子，或点击画布后用左右键。接满目标获胜，错过五颗结束。
5. 把目标改成 5、速度改低；预览重新开始。指出变量变化影响了规则，而不是只改了截图。
6. 勾选自查、写下一句发现。点「导出作品」下载带源码的单文件 HTML；「项目文件」导出完整模块 JSON。进阶路径见 [export-to-expert.md](export-to-expert.md)。

## 真实模型路径

设置中选 Codex（本机登录）或外部 API（服务端配置），**回首页新建作品**。输入一个具体小变体，例如「绿色太空任务倒计时，开始/暂停/重置，完成后庆祝」，选计时器起点。等待模型拆解，然后逐块生成；AI 可以选择不同模块和文件名。

本次固定中文太空计时器实测：一次规划 + 四次构建，171.7 秒、0 修复，10/10 浏览器行为检查；不是任意 prompt 的成功率保证。现场真实生成建议预留 3–6 分钟，不强行塞进 90 秒。

真实生成产物可直接打开 `reports/benchmarks/studio-live/preview.html`；`preview.png` 与 JSON 留下生成和运行证据。录制视频或事后展示时明确「已生成回放」。

## 故障与恢复

- 没有 API/登录：选择示例配方；界面明确显示模式，不会静默回退冒充 AI。
- 模型错误/超时：错误条会显示原因，原模块源码保留。重试同一块；不要刷新来制造第二个并行请求。
- 浏览器中途关闭：作品和已完成模块已写入本地服务端；回「我的作品」继续。请求仍可能在服务端完成；重新打开读取最终状态。
- 试玩没有反应：先确认交互模块已经搭建；必要时「重新运行预览」。真实 AI 可选中交互模块，在修改框描述期待和实际行为。
- 示例模式输入任意玩法：不会按自然语言重写，只支持预设参数；自由修改请新建 AI 作品。
- 导出给别人：HTML 可离线运行；保持同样的版本/模式说明。不要把调试截图写成客户成果。

## 讲清边界

今天可演示的是本地工坊和保留的专业工作台。没有已上线订阅、班级、儿童账户、公开社区、AR/VR 或被验证的教学效果。价目、渠道和融资是试验方案。验证数据只引用 [benchmark.md](benchmark.md) 与 [验收报告](delivery/acceptance.md)。
