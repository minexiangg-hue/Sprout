# Sprout · 芽芽工坊：来源登记

研究日期：2026-09-29。面向路演、商业计划与后续访谈；价格可能因地区、税费、促销及动态页面而变化。

## 研究方法和证据边界

先读取已安装的 Firecrawl、search、scrape 技能。环境未安装 `firecrawl` CLI；可调用的 Firecrawl MCP 三次检索均返回 `402 / Insufficient credits`。因此使用内置 web 搜索和页面读取完成研究，优先原始机构、产品官方页面和 benchmark 原作者仓库。未购买数据、未联系客户、未提交表单、未开展用户访谈。没有 Firecrawl 成功搜索 ID，故没有成功搜索可提交反馈。

本文件为可复查的来源台账，记录实际读到的结论及其限制，不是完整网页镜像。累计注册/累计覆盖不等于月活、独立付费用户或可获得市场；机构自报数值不等于第三方审计。产品文档的缺项不能证明产品没有某项功能。检索结果中的发布日期与网页内容版本不一致时，以明确日期的原文为准；无日期的当前页面仅按访问日记录。

## 可复述与不可复述

可复述：“Scratch 的官方影响力页面说明儿童创作已有大规模需求；我们仍需验证其中哪些家庭愿意为 AI 辅助、可理解的创作流程付费。”

不可复述：“全球 1.5 亿 Scratch 付费潜客”“儿童 AI 创作没有竞争对手”“比 Replit 更便宜且更强”“已证明提升编程能力”“已符合所有儿童隐私法规”。这些结论均未被本次研究证明。
